# Bill AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read attached bills with free vision models (stored per transaction), offer pre-fill on Add expense, warn when the bill total differs from the recorded amount, and explain the bill — the model never changes data or puts its own digits on screen.

**Architecture:** The provider-neutral LLM layer gains image input; a separate vision chain runs through the existing `ProviderRouter`, each provider wrapped so invalid JSON counts as `bad_output` (→ next model). `backend/src/billai/` builds the prompt, parses/validates/clamps, fetches page images from Cloudinary, and stores one `bill_reads` row per transaction keyed by a hash of its pages. Android shows a read card + mismatch row, an Explain sheet, and a pre-fill card.

**Tech Stack:** Next.js (`after()` from `next/server`), Drizzle, zod, vitest, `cloudinary` · Kotlin, Compose, Retrofit/Gson, `PdfRenderer`.

**Spec:** `docs/superpowers/specs/2026-10-11-bill-ai-design.md` (builds on `docs/superpowers/specs/2026-10-10-bills-design.md`).

## Global Constraints

- Schema changes in BOTH `backend/src/db/schema/*.schema.ts` (exported from `schema/index.ts`) and `backend/src/db/schema.ts`. **Never run `db:push`/DDL.**
- Routes: `withApi(..., { auth: 'required' })`, end with `export { corsPreflight as OPTIONS };`; reading routes `export const maxDuration = 60;`.
- Every statement scoped by `user_id`; bill pages only through `liveBill` + `status = 'ready'`; the server builds every Cloudinary URL itself.
- Nothing is sent to a model unless the request carries `aiConsent: true`.
- Displayed numbers come from validated fields, never from model prose; notes use placeholders `{total} {subtotal} {tax} {discount} {fees} {item:N}`.
- Daily cap `BILL_AI_MAX_PER_DAY` (default 60) per user per UTC day, counted on every model call (auto, retry, pre-fill).
- Android: `tr(R.string.x)` in en/hi/es/fr/de; `App*` components; theme colours; all numbers through masking (`MaskableAmountText` / `safeText`).
- Backend tests: `cd backend && npx vitest run`.

## Deliberate deviations from the spec (decided while planning)

- **Pre-fill images ≤ 1 MB each** (spec said 1.5 MB): 3 × 1.5 MB base64 ≈ 6 MB exceeds Vercel's 4.5 MB body limit. Phone sends ≤ 1600 px JPEG q70 (typically 150–400 KB).
- **`<think>`/fence stripping is a small local function** in `parse.ts` rather than the streaming `ToolTagFilter` (that class is built for token streams).
- **Validation runs inside the router** through a `validating()` provider wrapper (buffers the reply, throws `bad_output`), instead of a second retry loop.
- **Confirm triggers a read whenever `aiConsent` is true**; `run()` itself skips when a `done` row has the same `pages_key`, so replays cost nothing (no "became ready" flag needed).

## Review Focus

1. **Model wraps the JSON in prose / code fences / `<think>`** — must still parse; truly invalid output must fall through to the next model. Pinned by `parse.test.ts` + `validating.test.ts`.
2. **Pages change while a read runs** — the old result must not overwrite the new key. Pinned by the `pages_key` compare-and-set in Task 5 (`WHERE pages_key = key`) and `pagesKey` tests.
3. **Consent off** — no model call, row `no_consent`, cron never picks it. Pinned in Task 5 (`run` early return; cron selects only `queued`).
4. **Masked amounts in Explain / mismatch / pre-fill** — no clear digits. Pinned by `BillNotesTest` (masked fill) and `BillMismatchTest` (masked text).
5. **Update amount when the transaction changed or was deleted meanwhile** — must show the error toast, not crash; Undo restores the previous amount. Manual checklist (Task 9).

```ts
import { LlmError, type LlmChunk, type LlmProvider, type LlmRequest } from './types';

/**
 * Buffers a provider's whole reply and checks it. Invalid output becomes `bad_output`, which the router treats
 * like any failure (next model, short cool-down). Used where only a complete, valid JSON answer is useful.
 */
export function validating(p: LlmProvider, validate: (text: string) => void): LlmProvider {
  return {
    id: p.id, label: p.label, provider: p.provider, model: p.model, paid: p.paid,
    async *stream(req: LlmRequest): AsyncGenerator<LlmChunk> {
      let text = '';
      let end: LlmChunk = { type: 'end', reason: 'stop' };
      for await (const c of p.stream(req)) {
        if (c.type === 'text') text += c.text;
        else if (c.type === 'end') end = c;
      }
      try {
        validate(text);
      } catch (e) {
        throw new LlmError('bad_output', e instanceof Error ? e.message.slice(0, 200) : 'invalid output');
      }
      yield { type: 'text', text };
      yield end;
    },
  };
}
```

/** One non-streaming request with images through [router]. Throws AllProvidersFailed. */
export async function askWith(router: ProviderRouter, system: string, text: string, images: LlmImage[], maxTokens = 1800) {
  let out = '';
  let model = '';
  const events = router.run(() => ({ system, messages: [{ role: 'user', text, images }], tools: [], maxTokens, temperature: 0.1 }));
  for await (const ev of events) {
    if (ev.type === 'source') model = ev.provider.label;
    else if (ev.type === 'reset') out = '';
    else if (ev.chunk.type === 'text') out += ev.chunk.text;
  }
  return { text: out, model };
}

```ts
import { billReadSchema } from './schema';
import type { z } from 'zod';

export type BillRead = z.infer<typeof billReadSchema> & { checks: { itemsMatchSubtotal: boolean | null; totalsAddUp: boolean | null } };

const MAX_MONEY = 10_000_000;
const PLACEHOLDER = /\{(total|subtotal|tax|discount|fees|item:(\d+))\}/g;

/** The first {...} block, after removing <think> sections and code fences. */
export function extractJson(raw: string): string | null {
  const s = raw.replace(/<think>[\s\S]*?<\/think>/gi, '').replace(/```(?:json)?/gi, '');
  const a = s.indexOf('{');
  const b = s.lastIndexOf('}');
  return a === -1 || b <= a ? null : s.slice(a, b + 1);
}

/** Notes may mention money only through placeholders; any other run of 2+ digits is a made-up number. */
export function validNote(note: string, itemCount: number): boolean {
  let ok = true;
  const rest = note.replace(PLACEHOLDER, (_m, _k, n) => {
    if (n !== undefined && (Number(n) < 1 || Number(n) > itemCount)) ok = false;
    return '';
  });
  if (/\{[^}]*\}/.test(rest)) return false; // unknown placeholder
  return ok && !/\d{2,}/.test(rest);
}

const clamp = (n: number | null) => (n === null ? null : Math.round(Math.min(MAX_MONEY, Math.max(0, n)) * 100) / 100);
const near = (a: number, b: number) => Math.abs(a - b) <= 1;

export function parseBillRead(raw: string): BillRead {
  const json = extractJson(raw);
  if (!json) throw new Error('no JSON in reply');
  let obj: unknown;
  try {
    obj = JSON.parse(json);
  } catch {
    throw new Error('reply is not valid JSON');
  }
  const r = billReadSchema.parse(obj);
  const items = r.items
    .filter((i) => i.name)
    .slice(0, 100)
    .map((i) => ({ name: i.name, qty: i.qty === null ? null : Math.max(0, Math.min(i.qty, 10_000)), unitPrice: clamp(i.unitPrice), amount: clamp(i.amount) }));
  const total = clamp(r.total);
  const subtotal = clamp(r.subtotal);
  const tax = clamp(r.tax);
  const discount = clamp(r.discount);
  const fees = clamp(r.fees);
  const amounts = items.map((i) => i.amount);
  const base = subtotal ?? total;
  const itemsMatchSubtotal = items.length && base !== null && amounts.every((a) => a !== null)
    ? near(amounts.reduce((s, a) => s + (a as number), 0), base)
    : null;
  const totalsAddUp = subtotal !== null && total !== null ? near(subtotal + (tax ?? 0) + (fees ?? 0) - (discount ?? 0), total) : null;
  return {
    ...r, items, total, subtotal, tax, discount, fees,
    notes: r.notes.map((n) => n.trim().slice(0, 200)).filter((n) => n && validNote(n, items.length)).slice(0, 3),
    checks: { itemsMatchSubtotal, totalsAddUp },
  };
}
```

import { createHash } from 'node:crypto';
import { v2 as cloudinary } from 'cloudinary';
import { configureCloudinary, type CloudinaryCreds } from '../bills/cloudinary';

export const MAX_AI_IMAGE_BYTES = 1_048_576;
export type PageRef = { id: string; publicId: string; version: number | null; format: string | null; pages: number | null };

/** Identity of "these exact pages": a new, replaced or deleted page changes it. */
export function pagesKey(bills: { id: string; version: number | null; pages: number | null }[]): string {
  const parts = bills.map((b) => `${b.id}:${b.version ?? 0}:${b.pages ?? 1}`).sort();
  return createHash('sha256').update(parts.join('|')).digest('hex').slice(0, 32);
}

/** Bills in position order; each image is one page, each PDF page is one page; at most [max]. */
export function pagePlan(bills: PageRef[], max = 5) {
  const out: { publicId: string; version: number | null; page: number | null }[] = [];
  for (const b of bills) {
    const n = b.format === 'pdf' ? Math.max(1, b.pages ?? 1) : 0;
    if (n === 0) out.push({ publicId: b.publicId, version: b.version, page: null });
    else for (let p = 1; p <= n && out.length < max; p++) out.push({ publicId: b.publicId, version: b.version, page: p });
    if (out.length >= max) break;
  }
  return out.slice(0, max);
}

/** Signed, small JPEG of one page — what the model sees (≈150–300 KB). */
export function readImageUrl(c: CloudinaryCreds, publicId: string, version: number | null, page: number | null): string {
  configureCloudinary(c);
  return cloudinary.url(publicId, {
    type: 'authenticated', sign_url: true, secure: true, resource_type: 'image', format: 'jpg',
    ...(version ? { version } : {}),
    transformation: [{ crop: 'limit', width: 1600, height: 1600, ...(page ? { page } : {}) }, { quality: 70 }],
  });
}

/** Real type from the first bytes (never trust a declared MIME). */
export function sniffMime(base64: string): 'image/jpeg' | 'image/png' | 'image/webp' | null {
  const b = Buffer.from(base64.slice(0, 32), 'base64');
  if (b[0] === 0xff && b[1] === 0xd8 && b[2] === 0xff) return 'image/jpeg';
  if (b[0] === 0x89 && b.toString('latin1', 1, 4) === 'PNG') return 'image/png';
  if (b.toString('latin1', 0, 4) === 'RIFF' && b.toString('latin1', 8, 12) === 'WEBP') return 'image/webp';
  return null;
}

async function countRead(userId: string) {
  const [{ count }] = await db
    .insert(billReadCounts)
    .values({ userId, day: utcDay(new Date()), count: 1 })
    .onConflictDoUpdate({ target: [billReadCounts.userId, billReadCounts.day], set: { count: sql`${billReadCounts.count} + 1` } })
    .returning({ count: billReadCounts.count });
  checkDaily(count, config.billAi.maxPerDay);
}

async function livePages(userId: string, txId: string) {
  return db
    .select({ id: bills.id, publicId: bills.publicId, version: bills.version, format: bills.format, pages: bills.pages })
    .from(bills)
    .where(and(eq(bills.transactionId, txId), eq(bills.userId, userId), eq(bills.status, 'ready'), liveBill))
    .orderBy(asc(bills.position));
}

async function fetchImages(pages: Awaited<ReturnType<typeof livePages>>): Promise<LlmImage[]> {
  const c = requireCloudinary();
  const out: LlmImage[] = [];
  for (const p of pagePlan(pages)) {
    const r = await fetch(readImageUrl(c, p.publicId, p.version, p.page), { signal: AbortSignal.timeout(10_000) });
    if (!r.ok) throw new Error(`page fetch ${r.status}`);
    const buf = Buffer.from(await r.arrayBuffer());
    if (buf.length > 2 * 1024 * 1024) throw new Error('page image too large');
    out.push({ mime: 'image/jpeg', base64: buf.toString('base64') });
  }
  return out;
}

async function ask(images: LlmImage[], prefs: BillAiPrefs) {
  const { text, model } = await askWith(visionRouter(), buildBillPrompt(prefs), BILL_USER_TEXT, images);
  return { data: parseBillRead(text), model };
}

export const billReadService = {
  async get(userId: string, txId: string): Promise<ReadState> {
    await transactionService.getById(userId, txId);
    const pages = await livePages(userId, txId);
    const [row] = await db.select().from(billReads).where(and(eq(billReads.transactionId, txId), eq(billReads.userId, userId)));
    if (!row || pages.length === 0) return { status: 'none', data: null, model: null, stale: false };
    return { status: row.status, data: (row.data as BillRead | null) ?? null, model: row.model, stale: row.pagesKey !== pagesKey(pages) };
  },

  async run(userId: string, txId: string, opts: { consent: boolean; force?: boolean; prefs?: BillAiPrefs }): Promise<ReadState> {
    await transactionService.getById(userId, txId);
    const pages = await livePages(userId, txId);
    if (pages.length === 0) return { status: 'none', data: null, model: null, stale: false };
    const key = pagesKey(pages);
    const [row] = await db.select().from(billReads).where(and(eq(billReads.transactionId, txId), eq(billReads.userId, userId)));

    if (!opts.consent) {
      await db.insert(billReads).values({ transactionId: txId, userId, status: 'no_consent', pagesKey: key })
        .onConflictDoUpdate({ target: billReads.transactionId, set: { status: 'no_consent', pagesKey: key, updatedAt: new Date() } });
      return this.get(userId, txId);
    }
    if (row && row.status === 'done' && row.pagesKey === key && !opts.force) return this.get(userId, txId);

    await countRead(userId); // throws 429 DAILY_LIMIT
    await db.insert(billReads).values({ transactionId: txId, userId, status: 'queued', pagesKey: key })
      .onConflictDoUpdate({ target: billReads.transactionId, set: { status: 'queued', pagesKey: key, updatedAt: new Date() } });

    try {
      const { data, model } = await ask(await fetchImages(pages), opts.prefs ?? DEFAULT_PREFS);
      // Compare-and-set: pages changed during the read → this result is for old pages, drop it.
      await db.update(billReads).set({ status: 'done', data, model, error: null, attempts: 0, updatedAt: new Date() })
        .where(and(eq(billReads.transactionId, txId), eq(billReads.pagesKey, key)));
    } catch (e) {
      const attempts = (row?.pagesKey === key ? row.attempts : 0) + 1;
      await db.update(billReads)
        .set({ status: attempts >= MAX_ATTEMPTS ? 'failed' : 'queued', attempts, error: e instanceof AllProvidersFailed ? 'models unavailable' : 'read failed', updatedAt: new Date() })
        .where(and(eq(billReads.transactionId, txId), eq(billReads.pagesKey, key)));
      logger.warn('Bill read failed', { txId, attempts, message: e instanceof Error ? e.message.slice(0, 200) : String(e) });
    }
    return this.get(userId, txId);
  },

  /** Pre-fill: read images the phone sent, store nothing. */
  async readImages(userId: string, images: LlmImage[], prefs: BillAiPrefs) {
    await countRead(userId);
    return ask(images, prefs);
  },

  /** Cron: queued rows (only ever created by a consenting request), oldest first. */
  async retryQueued(limit = 50): Promise<number> {
    const rows = await db.select({ txId: billReads.transactionId, userId: billReads.userId })
      .from(billReads).where(and(eq(billReads.status, 'queued'), lt(billReads.attempts, MAX_ATTEMPTS)))
      .orderBy(asc(billReads.updatedAt)).limit(limit);
    for (const r of rows) {
      await this.run(r.userId, r.txId, { consent: true }).catch((e) => logger.warn('Bill read retry failed', { txId: r.txId, message: String(e).slice(0, 200) }));
    }
    return rows.length;
  },
};

/** Pure Bill AI helpers: pre-fill, mismatch, notes. Every number shown comes from parsed fields. */
object BillAi {
    const val MIN_CONFIDENCE = 0.5
    private const val MASK = "★★★★★"

    data class Prefill(val amount: Double?, val note: String?, val date: LocalDate?, val category: String?)

    /** Only for confident reads; never a future date; category only if the user has it (case-insensitive). */
    fun prefill(read: BillReadDto, today: LocalDate, categories: List<String>): Prefill? {
        if (read.confidence < MIN_CONFIDENCE) return null
        val date = read.date?.let { runCatching { LocalDate.parse(it) }.getOrNull() }?.let { if (it.isAfter(today)) today else it }
        val category = read.category?.let { c -> categories.firstOrNull { it.equals(c, ignoreCase = true) } }
        val p = Prefill(read.total?.takeIf { it > 0 }, read.merchant, date, category)
        return if (p.amount == null && p.note == null && p.date == null && p.category == null) null else p
    }

    /** More than ₹1 apart (rounding is not a mismatch). */
    fun differs(recorded: Double, total: Double?): Boolean = total != null && abs(recorded - total) > 1.0

    private val placeholder = Regex("""\{(total|subtotal|tax|discount|fees|item:(\d+))\}""")

    fun fillNote(note: String, read: BillReadDto, masked: Boolean): String = placeholder.replace(note) { m ->
        val v: Double? = when (m.groupValues[1]) {
            "total" -> read.total; "subtotal" -> read.subtotal; "tax" -> read.tax; "discount" -> read.discount; "fees" -> read.fees
            else -> read.items.getOrNull(m.groupValues[2].toInt() - 1)?.amount
        }
        when { v == null -> "—"; masked -> MASK; else -> formatInr(v) }
    }

    fun prefs(language: String, style: String, tone: String) = BillAiPrefsDto(language, style, tone)

import kotlinx.coroutines.withContext
import java.io.ByteArrayOutputStream

/** Small JPEGs (≤ 1600 px, ≤ 1 MB) of up to 3 pages for the pre-fill read. PDFs are rendered on the phone. */
object AiImages {
    private const val SIDE = 1600
    private const val MAX = 1_000_000

    suspend fun prepare(context: Context, picked: List<Picked>): List<BillImageDto> = withContext(Dispatchers.IO) {
        val out = mutableListOf<BillImageDto>()
        for (p in picked) {
            if (out.size >= 3) break
            if (p.mime == "application/pdf") {
                context.contentResolver.openFileDescriptor(p.uri, "r")?.use { fd ->
                    PdfRenderer(fd).use { pdf ->
                        for (i in 0 until minOf(pdf.pageCount, 3 - out.size)) pdf.openPage(i).use { page ->
                            val (w, h) = BillImages.targetSize(page.width * 2, page.height * 2, SIDE)
                            val bmp = Bitmap.createBitmap(w, h, Bitmap.Config.ARGB_8888).apply { eraseColor(Color.WHITE) }
                            page.render(bmp, null, null, PdfRenderer.Page.RENDER_MODE_FOR_DISPLAY)
                            jpeg(bmp)?.let { out += it }
                        }
                    }
                }
            } else {
                BillImages.prepare(context, p.uri, p.mime).getOrNull()?.let { prepared ->
                    val bmp = android.graphics.BitmapFactory.decodeFile(prepared.file.absolutePath)
                    prepared.file.delete()
                    if (bmp != null) {
                        val (w, h) = BillImages.targetSize(bmp.width, bmp.height, SIDE)
                        jpeg(if (w == bmp.width) bmp else Bitmap.createScaledBitmap(bmp, w, h, true))?.let { out += it }
                    }
                }
            }
        }
        out
    }

    private fun jpeg(bmp: Bitmap): BillImageDto? {
        for (q in intArrayOf(70, 55, 40)) {
            val bytes = ByteArrayOutputStream().also { bmp.compress(Bitmap.CompressFormat.JPEG, q, it) }.toByteArray()
            if (bytes.size <= MAX) return BillImageDto("image/jpeg", Base64.encodeToString(bytes, Base64.NO_WRAP))
        }
        return null
    }
}
